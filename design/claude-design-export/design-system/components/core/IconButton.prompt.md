Icon-only square button for header/toolbar actions; always pass a Korean `label`.

```jsx
<IconButton icon="x" label="닫기" />
<IconButton icon="history" label="기록" active />
<IconButton icon="settings-2" label="설정" size="sm" />
```

Props: size sm 28 / md 36; variant ghost (default) or secondary (bordered); `active` tints ink-50.
