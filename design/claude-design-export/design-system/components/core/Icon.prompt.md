Lucide stroke icon that inherits currentColor; use beside text, never as the only label except inside IconButton.

```jsx
<Icon name="hand" size={20} />
<Icon name="circle-check" size={16} style={{ color: 'var(--ink-600)' }} />
```

Sizes: 16 inline with labels, 18 in 36px controls, 20 in the hero action/empty states. Vocabulary: hand 막힘, bookmark 저장, circle-check 확인, circle-help 추론, mic Tiro, monitor Meet, code-xml IntelliJ, history 기록, arrow-left 돌아가기, refresh-cw 다시 연결. Never use "sparkles".
