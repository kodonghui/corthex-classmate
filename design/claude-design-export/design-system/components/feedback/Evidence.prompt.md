Marks how the tutor knows each claim; put one on every claim.

```jsx
<Evidence type="verified" source="tiro" />            // 확인됨 · 전사
<Evidence type="partial" source="meet" />             // 일부 확인 · Meet 화면
<Evidence type="inferred" reason="테스트 이야기" />    // 추론 · 테스트 이야기 (dashed)
<Evidence type="delayed" source="intellij" />         // 자료 지연 · IntelliJ
```
