Quick follow-up chips shown under an answer so the learner never has to type a question.

```jsx
<ChipGroup>
  <Chip icon="minimize-2" onClick={...}>더 쉽게</Chip>
  <Chip icon="list">예시 더</Chip>
  <Chip icon="code-xml">코드로</Chip>
  <Chip selected>3교시</Chip>
</ChipGroup>
```

28px tall, hairline border, ink-50 tint when `selected`. Also used as filters in 기록.
