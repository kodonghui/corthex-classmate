If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.
If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Quick rules that matter most for this brand:
- The surface is a 360–520 px wide vertical panel (default 380 × 900). The teacher's transcript is the biggest thing on screen; chrome stays small and gray.
- Catching a stuck moment never requires typing: tap a dotted word (TranscriptFlow) or a sentence; the answer is a MarginNote under that sentence.
- Warm paper neutrals, ink text, one ink-blue accent (`--ink-600`). No purple, no gradients, no emoji, no card shadows, very few icons.
- Korean 해요체; verbs 붙잡다 / 접히다 / 남다 / 돌아가다; buttons say what the learner would say ("수업으로 돌아가기", "더 쉽게").
- One-sentence conclusion first, details behind Disclosure, every claim tagged with Evidence (확인됨 / 일부 확인 / 추론 / 자료 지연).
- Status is one quiet SourceFooter line; amber says what stopped and what continues, red only when the tutor is unreachable.
