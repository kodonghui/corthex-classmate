# Windows 설치 · 0.0.6-beta2

이 버전은 **질문 자료 흐름도와 Claude 연결 조건을 추가한 안내 보강판**입니다. 확장 버전은 0.0.6이며 beta1과 프로그램 파일이 같습니다. beta1 사용자는 새 안내만 읽으면 됩니다.

## 받을 파일

- **Corthex-Classmate-0.0.6-beta2-windows-x64.zip** — 설치 프로그램·Chrome 확장·안내서·라이선스 전체
- **Guide.html** — 한국어 안내서, 다운로드 후 브라우저에서 열기
- **…zip.sha256** — 파일 무결성 확인용

GitHub의 **Source code (zip/tar.gz)**는 설치 파일이 아닙니다. 위 이름의 Windows ZIP을 받으세요.

## 설치

Chrome + 본인 Windows Claude Code CLI 설치·로그인 + Tiro 준비 → ZIP 전체 압축 해제 → **Install.cmd** → Chrome 완전 재시작 → `chrome://extensions` 개발자 모드에서 설치 완료 화면의 확장 폴더 추가.

설치기가 같은 PC의 Claude Code 실행 파일을 찾습니다. Claude 웹/데스크톱 앱, WSL 전용 설치, 다른 PC의 CLI는 자동 연결 대상이 아닙니다. 로그인·AI 답변 성공은 별도로 확인하세요.

## 주의

현재 Claude만 지원하며 Codex는 비활성입니다. 각자 계정의 한도·비용이 적용됩니다. 최신 전문 정보·상시 웹 검색·무제한 기억을 보장하지 않습니다.
서명되지 않은 Windows x64 베타이며 기존 설치를 덮어쓰지 않습니다. 자동 업데이트가 없고 백신·보안 정책을 끄면 안 됩니다.
개발 PC의 격리 설치·패키지 검증은 통과했지만 새 PC의 실제 계정 로그인·수업 전체 흐름은 미검증입니다.
