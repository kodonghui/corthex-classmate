# Corthex Classmate 0.1.0

## 달라지는 사용 흐름

1. 위 **선생님 전사**에서 듣고 읽습니다. 단어/문장을 누르면 질문한 순간의 맥락을 붙잡습니다.
2. 아래 **나의 공부 대화**에 답·근거·그림이 모입니다. 과거 답이 새 질문 때문에 사라지지 않습니다.
3. 전사의 **대화 보기**로 해당 대화에 이동합니다. **이 대화에 이어 묻기**는 해당 질문의 맥락을 유지하고 **새 질문**은 최근 수업을 기준으로 합니다.
4. 이해에 도움이 되면 AI가 그림을 함께 만듭니다. 직접 원하는 경우 그림 종류를 고르고 **그림 요청**을 누른 뒤 질문을 추가하거나 전송합니다.
5. **크게 보기**에서 확대·축소하고 Esc로 돌아옵니다. 글 설명도 함께 남습니다.
6. 경계선을 끌거나 키보드 위아래 화살표로 비율을 조절합니다. **대화 넓게**로 읽을 공간을 확보할 수 있습니다.

| 도식 | 적합한 설명 |
|---|---|
| 순서도 | 처리 순서·조건 분기 |
| 시퀀스 | 참여자 사이 시간순 메시지 |
| 스윔레인 | 역할별 담당 단계 |
| 상태도 | 상태가 바뀌는 조건 |
| 개념도 | 개념 사이 관계 |
| 계층도 | 포함·상하 구조 |
| 타임라인 | 시간순 사건 |
| 비교표 | 동일 기준의 차이 |

스윔레인은 Mermaid의 안정된 flowchart/subgraph를 통해 역할별 구획으로 표시합니다. timeline/비교표는 실행 코드 없는 React 템플릿입니다. 그림은 AI 설명을 시각화한 것이며 독립적으로 검증된 사실이 아닙니다.

## 호환성과 개인정보

- 이전 질문·답 데이터는 삭제하거나 변환해 덮어쓰지 않습니다. 선택적인 그림 JSON이 로컬 답 사건과 V2 읽기 모델에 포함됩니다. 과거 기록에서 다시 표시합니다.
- 질문 입력은 4,096 UTF-8 바이트 제한입니다. 답변 전체가 40자인 것은 아닙니다. 첫 결론만 40자, 상세 설명은 별도입니다. 그림은 가독성과 렌더 자원 보호를 위해 12 노드·24 관계까지입니다.
- 로컬 보관 / 선택한 AI 제공자로 전송될 수 있음 / Corthex 서버 기본 전송 없음.
- 사용자별 Tiro·Windows Claude Code CLI 설치/로그인이 필요합니다. 현재 Codex 선택은 비활성입니다.
- 법·세무·회계의 최신 정보 및 웹 검색을 보장하지 않습니다. 전문 정보는 공식 자료로 별도 확인해야 합니다.
