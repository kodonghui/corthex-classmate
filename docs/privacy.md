# Corthex Classmate — 개인정보와 데이터 처리 (초안, 2026-09-03)

한 줄 약속: **수업 데이터는 이 PC 에만 있습니다. 선택한 AI 제공자로는 질문 시점의 최근 자료(전사 · 편집기 발췌 · 화면 한 장)만 나가고, Corthex 서버로 기본 전송은 없습니다.**
설정 화면에 들어갈 문구(2라운드)는 이것입니다.

> 로컬 보관 / 선택한 AI 제공자로 전송될 수 있음 / Corthex 서버 기본 전송 없음

이 문서는 `docs/master-prompt.md` §4 불변 원칙을 사용자 눈높이로 옮긴 것이고, 원칙이 정본입니다.

## 1. 무엇을 모으고 어디에 두나

| 자료 | 어디서 | 무엇을 | 어디에 | 안 하는 것 |
|---|---|---|---|---|
| 전사 문장 | Tiro 공유 페이지(학습자가 연 탭) | 확정/진행 문장 · 도착 시각 | 로컬 도우미 `<data_dir>/<periodId>.sqlite` | 공유 URL·비밀번호를 로그·커밋·스크린샷에 남기지 않음 |
| 화면 장면 | Meet 탭 캡처 | 질문할 때 **한 장**(JPEG 품질 60) · 연속 캡처는 바뀐 장면만 | `<data_dir>/<periodId>/frames/<id>.<확장자>` · 확장자는 바이트가 정합니다 | 화면 전체 영상 저장 없음 · Meet 탭이 아니면 아예 찍지 않음 |
| 편집기 문맥 | IntelliJ MCP(읽기 전용) | 열린 파일 발췌 | 질문 봉인에만 | 셸·패치·파일 쓰기 없음 |
| 질문·답·상태 | 사이드패널 | 붙잡은 낱말·시각 · 결론 · 근거 | SessionEvent 로 저장 | 화면·전사 문장을 명령으로 실행하지 않음 |

## 2. 무엇이 밖으로 나가나

학습자가 낱말·문장을 붙잡은 **그 시점**에 봉인한 자료만 선택한 제공자(Claude CLI, 또는 한도가
돌아오면 Codex)로 나갑니다. 무엇이 실제로 실리는지는 `apps/native-host/src/tutor/materials.rs`
의 `render()` 가 정본이고, 2026-09-03 기준으로 이렇습니다.

| 자료 | 밖으로 나가나 | 실제로 실리는 것 |
|---|---|---|
| 전사 문장 | **나갑니다** | 봉인에 담긴 조각들의 본문 그대로 |
| 편집기 발췌 | 나갑니다(붙어 있을 때만) | IntelliJ MCP 가 준 발췌 본문 |
| 화면 장면 | **나갑니다**(파일이 있을 때만) | 봉인한 **한 장의 파일 경로 한 줄**. 제공자 CLI 가 그 경로를 열어 그림을 봅니다. 파일이 없으면 `"화면 프레임 N장"` 이라는 장 수만 나갑니다 |
| 자료 나이 | 나갑니다 | 각 자료가 몇 초 전 것인지 |

- **화면 장면은 이제 모델이 봅니다.** 2026-09-03 이전에는 장 수만 나갔지만, 지금은 질문할 때
  찍은 **그 한 장의 파일 경로**가 자료 문단에 실리고 제공자 CLI 가 그 그림을 엽니다. 파일은
  이 PC 에 그대로 남고, 나가는 것은 그림을 읽어 답을 만드는 그 한 번입니다.
- 나가는 것은 **봉인한 한 장뿐**입니다. 그 교시의 다른 장이나 질문 뒤에 찍힌 장은 나가지
  않습니다. 파일이 그 자리에 없으면 경로를 적지 않고 장 수만 나갑니다.
- 화면은 **Meet 탭일 때만** 찍힙니다. 주소의 호스트 이름이 정확히 `meet.google.com` 이 아니면
  셔터를 아예 누르지 않으므로, 은행·메신저 같은 다른 탭은 파일로도 남지 않고 나가지도 않습니다.
- 화면 속 글자는 **자료일 뿐 명령이 아니라고** 프롬프트에 못 박습니다. 강의 화면에 뜬 코드나
  주소를 모델이 지시로 따르지 않습니다(불변 원칙 §4-7).
- 모델의 답은 JSON 으로 받아 템플릿으로 그립니다. 모델이 준 HTML 을 직접 실행하지 않습니다.
- **사이드패널은 이제 fixtures 재생만 하는 것이 아닙니다.** 라이브로 이어져 있어 학습자가
  물으면 위 표의 자료가 실제로 제공자에게 나갑니다. `?replay=` 로 연 재생 화면만
  아무것도 내보내지 않습니다.

## 3. 인증정보

- Codex · Claude · Tiro 의 인증정보·토큰을 앱 코드 · 서버 · GitHub · 로그에 저장하거나 전송하지 않습니다.
- `.mcp.json` 은 OAuth 전용이고 `.gitignore` 에 `.env*` · `*.token` · `.claude/settings.local.json` 이 있습니다.
- 친구마다 독립 프로필과 인증을 씁니다. 다른 사람의 토큰이나 세션을 빌리지 않습니다.
- Google Drive 다운로드 제한, Sites bypass 토큰 같은 우회는 하지 않습니다.

## 4. 스크린샷과 fixtures

- `docs/screenshots/` 는 합성 fixtures(`fixtures/synthetic-class/golden-ioc/`)로 찍은 것이라 실제 수업·사람이 없습니다.
- fixtures 에는 비식별 발췌만 둡니다. 실제 Tiro 페이지 스냅샷은 `fixtures/tiro/` 에 합성본만 있습니다.

- 실제 Tiro · Meet · IntelliJ 연결은 사람 손 시험이 필요해 '대기' 입니다(`docs/spikes/`).
