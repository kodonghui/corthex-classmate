# 전사 아래 문답 · 그림 보기 · Cowork 자료 전달

2026-09-07 사용자 실사용 피드백. 확장 0.1.1 패치이며 호스트 프로토콜/DB는 변경하지 않습니다. 공개 설치 ZIP 0.1.0과는 별개의 로컬 업데이트입니다.

## 표시 변경

0.1.0의 위 전사/아래 대화 분리에서, 원 전사 문단 바로 아래에 해당 질문과 설명·후속·그림을 표시합니다. 최신 사용자 요청이 이전 상하 분리 결정을 대체합니다. 자유 질문도 질문 시점에 저장한 전사 ID를 사용합니다. 해당 전사가 현재 화면에 없으면 '이전 자료에 대한 질문'에 남기며 새 문단으로 임의 이동하거나 삭제하지 않습니다. 입력기는 하단에 고정하고 '새 질문'으로 선택한 대목을 해제합니다.

그림 확대 창은 좁은 너비에서도 맞추며 확대 시 가로 스크롤을 제공합니다. '맞춤'은 배율뿐 아니라 스크롤 위치도 복귀시킵니다. 사용자 사진의 정확한 잘림은 합성 예시에서 재현하지 못했고, 폭·배율·긴 레이블 회귀 검사를 보강했습니다.

## 속도 진단 (설정 변경 없음)

- 현재 Claude 실행 인자에 effort 지정은 없습니다. 해당 PC 사용자 설정은 medium, 모델 설정은 opus 별칭입니다. 실행 중인 개별 응답의 실제 모델/effort를 기록에서 확정한 것은 아닙니다.
- 2026-09-07 한 세션의 저장된 질문→최종 답변 80건: 중앙값 18초, p90 62초, 11~157초. 최근 20건 중앙값 20초/p90 39초. 그림 3건 29~50초(중앙값 38초). 누적 기록에는 대기/재시도도 포함될 수 있으며 원인별 소요시간은 분리할 수 없습니다.
- MCP 자동 연결은 --strict-mcp-config로 이미 제외합니다. 기본 제공자는 질문마다 새 프로세스를 띄웁니다. 상주 세션 제공자는 opt-in으로 존재하지만 실제 CLI 검증이 미완료라 자동 활성화하지 않습니다.
- 최근 문답은 최대 6개/12,000자, 최근 자료는 2,000자 기본 한도입니다. 현재 스트리밍은 결론만 추출하며 상세 본문과 그림은 완성 뒤에 나옵니다.
- 추천: 첫 글자/전체 완료/대기/재시도 계측 → 상세 본문 점진 표시 → 필요한 문답 선별과 전용 실행 컨텍스트 확인 → 동일 합성 질문으로 medium/low 및 지원되는 빠른 모델 품질 비교. 낮은 effort 또는 병렬 모델 호출을 사용자 동의 없이 켜지 않습니다.
- 공식 참고: https://code.claude.com/docs/en/model-config (2026-09-07 확인)

## Cowork로 블로그 초안 작성

원본은 `%LOCALAPPDATA%/CorthexClassmate/sessions`의 SQLite와 세션별 화면입니다. 원본 폴더 대신 독립 사본을 연결하세요. `apps/native-host/scripts/export-cowork.mjs`는 명시한 세션 하나를 읽기 전용 session.bundle 요청으로 읽고, 새 출력 폴더에 다음을 만듭니다. 모델 호출/인터넷 전송/원본 DB 수정은 하지 않습니다. 현재 Native Messaging 1 MiB 응답 한도를 넘는 세션은 지원하지 않고 오류로 중단합니다.

- `01-study-source.md`: 세그먼트별 최신 전사, 모든 질문, 질문 ID로 연결된 답변과 화면 참조.
- `session-bundle.json`: 중간 전사 판본·시각·자료 연결을 보존한 V2 번들.
- `frames/`: 실제 확장자대로 복사한 화면.
- `export-manifest.json`: 사본 자산의 해시와 내보낸 시각.
- `README.md`: 비공개/읽기 경계.

Cowork에 새 폴더를 연결하고 수업 흐름+개인 질문을 함께 다룬 개인 복습 노트/공개 블로그 초안/단순 본문 HTML/근거 검증표를 요청합니다. 결과만 output/에 작성하고 Notion/Tistory 자동 발행은 요청하지 않습니다. 강의 화면·개인정보는 공개 초안에 자동 삽입하지 않습니다. 복습 자료를 넣는다고 자동으로 공개 권한이 생기지는 않습니다.
