어디까지 참고하나요?

  • 전사: 누른 문단을 중심으로 약 2,000자 예산에서 앞뒤를 고릅니다. 중심 문단 자체가 길면 그 문단은 예산을 넘어도 유지합니다. 문단을 고르지 않고 질문하면 가장 최근 전사 대목이 중심입니다.
  • 뒤에 이어진 말씀: 질문할 때 이미 도착한 전사 중, 중심 문단 도착 시각에서 30초 이내인 뒤쪽 조각을 먼저 담고 남은 예산에 앞쪽을 넣습니다. 질문 후 30초를 기다리거나 앞으로 하실 말씀까지 듣는 기능은 아닙니다.
  • 화면: 질문을 처리할 때 선택한 강의 탭의 화면 한 장을 새로 캡처하려고 시도합니다. 최대 1.5초 안에 성공하면 새 화면으로 바꿉니다. 실패하면 기존에 선택된 화면이 남을 수 있고, 그것도 없으면 화면 없이 답합니다. 전체 영상을 AI가 계속 시청하는 방식은 아닙니다.
  • 이미지 전달: 저장된 캡처 파일이 있으면 해당 이미지의 경로를 Claude Code에 전달해 참고하도록 합니다. 파일 경로 전달만으로 매 답변에서 이미지 읽기가 성공했다고 보장할 수는 없습니다. 답이 화면과 맞지 않으면 화면 상태와 캡처 시각을 확인하세요.
  • 이전 대화: 같은 교시의 완료된 최근 문답을 최대 6쌍·합계 약 12,000자 한도로 전달합니다. 오래되거나 긴 내용은 제외·잘릴 수 있습니다. 다른 교시나 하루 전체를 전부 기억하는 것은 아닙니다.
  • 코드: 실제 편집기 연결로 받은 발췌가 있을 때만 추가로 포함합니다. IntelliJ를 연결하지 않아도 질문할 수 있습니다. 로컬 프로젝트 전체나 Notion·PDF를 자동으로 읽어 넣는 기능은 아닙니다.

“더 쉽게 설명해줘”라고 이어 물으면?

앞 질문에 붙은 이어 묻기는 그 질문이 참고하던 전사 대목을 유지합니다. 그 사이 수업이 다른 주제로 넘어가도 원래 대목을 설명하도록 하는 방식입니다. 화면은 새로 캡처할 수 있으므로, 예전 문단을 질문하면 옛 설명과 현재 화면이 서로 다를 수 있습니다. 필요하면 영상을 해당 장면으로 되돌려 질문하세요.

AI는 위 자료 외에 학습한 일반 지식으로 설명을 보충할 수 있습니다. 보충 설명을 강사가 실제로 말한 내용과 동일하게 보지 마세요. Classmate가 매 질문마다 웹을 검색하거나 Notion·Drive 전체를 읽는다고 가정하면 안 됩니다. 전사 오류도 답에 영향을 줄 수 있습니다.

자동 연결 / 조건을 확인하세요

친구의 그 PC에 Claude Code가 있으면 자동으로 찾습니다

친구 PC의 Windows용 Claude Code 설치·본인 로그인 → Install.cmd → Chrome 확장 추가·재시작 순서입니다. 설치기가 그 PC의 실행 파일을 찾고 로컬 연결을 등록하므로 일반적인 설치 경로라면 경로를 직접 입력할 필요가 없습니다.

  • 지원: 같은 Windows 사용자 계정의 native Claude Code 또는 최신 npm 설치 안의 native claude.exe. PATH와 일반 설치 위치를 탐색합니다.
  • 자동 연결 아님: Claude 웹/데스크톱 앱만 로그인한 경우, WSL 안에만 설치한 경우, Claude가 다른 물리적 PC에만 있는 경우. 다른 컴퓨터의 Claude를 원격으로 찾아 연결하지 않습니다.
  • 예외: 비표준 위치는 자동 탐색에 실패할 수 있습니다. Diagnose.cmd 결과를 개발자에게 알려주세요. 설치기는 토큰을 복사하거나 로그인·AI 요청을 대신하지 않습니다.

‘실행 파일을 찾았다’는 ‘로그인과 답변이 확인됐다’는 뜻이 아닙니다. 본인 Claude Code에서 정상적으로 대화할 수 있는지 먼저 확인하고, Classmate에서도 첫 질문을 보내 보세요. 사용 한도·네트워크·CLI 버전 때문에 실패할 수 있습니다.

01 / 내 계정 준비

Chrome·Claude Code·Tiro를 준비하세요

  1. Chrome과 공식 Claude Code Windows 버전을 설치하세요. Classmate 개발용 Git·Node·Rust는 필요 없습니다. Claude Code 자체의 요구사항은 공식 안내를 따르세요.
  2. 터미널에서 claude를 실행해 본인 계정으로 로그인하고 처음 실행 안내를 마치세요. Windows native claude.exe가 필요합니다. 최신 npm 설치본 내부의 native 실행 파일도 자동으로 찾습니다. WSL 안에만 설치된 CLI나 native 실행 파일이 없는 옛 npm 설치는 지원하지 않습니다.
  3. Tiro도 본인 계정으로 준비하세요. 녹음과 전사는 Tiro가 합니다. Classmate만으로 자동 녹음되는 것은 아닙니다.

Claude와 Tiro 요금·사용량 제한은 각자의 계정/구독에 따릅니다. AI 사용량은 소비되며, API 과금 인증을 별도로 설정한 환경에서는 그 설정이 적용될 수 있습니다. 이 패키지가 무료 무제한 사용을 제공하지 않습니다.

02 / 프로그램 설치

압축을 전부 풀고 Install.cmd를 실행하세요

  1. ZIP에서 ‘모두 압축 풀기’를 누르세요. ZIP 안에서 파일 하나만 직접 실행하지 마세요.
  2. Install.cmd를 더블클릭하세요. 파일 검증 후 설치하고 마지막에 확장 폴더 경로를 보여줍니다.
  3. Chrome 창을 모두 닫았다가 시작 메뉴에서 다시 여세요. 연결이 안 되면 Windows 로그아웃·로그인 후 다시 여세요. 작업 중인 탭은 먼저 저장하세요.

설치 위치: %LOCALAPPDATA%\Programs\CorthexClassmate\[버전]

관리자 권한은 필요 없습니다. 설치 스크립트가 실행되는 프로세스에만 실행 정책 옵션이 적용되며, Windows의 전역 보안 설정을 바꾸지 않습니다. 서명된 설치 EXE가 아니므로 배포자와 ZIP의 SHA-256을 확인하세요. 백신이나 회사 보안 정책을 끄지 마세요. 기존 Classmate가 등록되어 있으면 덮어쓰지 않고 중단합니다. 이전 공식 ZIP 설치 사용자는 먼저 이전 묶음의 Disconnect.cmd로 연결만 해제한 뒤 새 Install.cmd를 실행하세요. 학습 자료는 삭제되지 않습니다. Chrome에서 새 버전의 app/extension 경로를 다시 로드해야 합니다. 개발용 C:\\CorthexClassmate 설치는 유지보수 담당자에게 업데이트를 요청하세요.

03 / Chrome에 추가

한 번만, 확장을 직접 선택하세요

  1. Chrome 주소창에 chrome://extensions를 입력하세요.
  2. 오른쪽 위 ‘개발자 모드’를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’를 누르세요.
  3. 설치 마지막에 나온 …\app\extension 폴더를 선택하세요. ZIP을 푼 임시 폴더 대신 설치된 폴더를 골라야 합니다.
  4. Corthex Classmate를 툴바에 고정하세요.

로컬 도우미 EXE만 실행한다고 확장이 설치되지는 않습니다. Chrome의 확장 추가 단계는 사용자가 직접 합니다. Chrome 공식 안내

04 / 첫 수업

영상과 전사를 연결하고 한 번 질문해 보세요

  1. Tiro에서 녹음을 시작하고 본인 녹음의 공유 페이지를 같은 Chrome 프로필에서 열어 두세요. 화면에 전사가 실제로 나타나는지 확인하세요.
  2. 컴퓨터의 강의 영상을 사용할 때는 Tiro 데스크톱에서 시스템 사운드 입력을 이용할 수 있습니다. 마이크와 시스템 소리를 중복 입력하지 않도록 Tiro의 입력 설정을 확인하세요.
  3. 강의 영상/회의 탭으로 돌아가 그 탭에서 Classmate 확장 아이콘을 누르세요. 해당 탭을 선택해야 질문 순간의 화면을 참고할 수 있습니다.
  4. 설정에서 목적을 ‘수업 / 시험 공부 / 회의’ 중 고르고 주제를 적으세요. 목적·주제 변경은 다음 새 세션에서 적용됩니다.
  5. 전사에서 모르는 단어나 문장을 누르거나 질문을 적으세요. 첫 설명을 받은 뒤 다른 문단에 질문해서 앞 설명도 남는지 확인하세요.

Meet에서 소리가 전달되지 않는 현장 수업은 주변 음성을 Tiro가 따로 받아야 합니다. 휴대폰 Tiro도 활용할 수 있습니다. 마이크·녹음·화면 공유는 강사·참가자의 허용 범위와 서비스 정책을 지켜 주세요.

안 되면 여기부터

증상확인할 것
설치가 중단됨Diagnose.cmd를 실행해 패키지 파일·등록·Claude 경로를 확인하세요. ‘기존 설치 있음’은 보호 장치이므로 개발자에게 문의하세요.
전사가 안 들어옴Tiro가 녹음 중인지, 본인의 공유 페이지가 같은 Chrome에서 열려 있고 전사가 늘어나는지 확인하세요.
로컬 도우미 연결 안 됨설치된 확장 폴더를 로드했는지 확인하고 Chrome을 완전히 재시작하세요.
답이 안 옴Claude Code 직접 로그인·사용 한도·인터넷 연결을 확인하세요. 진단 성공은 AI 답변 성공이나 로그인 완료를 뜻하지 않습니다.
화면을 못 찍는다고 함영상 탭을 앞으로 가져오고 그 탭에서 확장 아이콘을 다시 누르세요. 다른 화면으로 이동하면 다시 선택해야 할 수 있습니다.

이 묶음에는 배포자의 수업 기록·캡처·계정 인증을 넣지 않았습니다. 내 기록은 기본적으로 %LOCALAPPDATA%\CorthexClassmate\sessions에 보관됩니다. 같은 Windows 계정을 공유하면 이 저장소도 공유될 수 있습니다. 서로 다른 사람은 각자의 Windows 계정을 사용하세요.

Disconnect.cmd는 이 설치본이 소유한 Chrome 연결만 해제합니다. 프로그램 파일과 공부 기록은 지우지 않습니다. Chrome 확장 삭제는 확장 관리 화면에서 직접 하세요.

자동 업데이트는 없습니다. 새 버전은 배포자에게 받으세요. 기존 설치 마이그레이션은 아직 자동 지원하지 않습니다. 임의로 기록 폴더를 삭제하거나 새 버전을 덮어쓰지 마세요.
