# fixtures/meet — Meet 화면 발췌 자리

**지금은 실제 데이터가 없습니다.** 화면 캡처 관련 확인은
`fixtures/synthetic-class/golden-ioc/frames/` 의 자리표시자 WebP 로 합니다.

## 무엇을 넣는 곳인가

Meet 탭 캡처(`tabCapture` + Offscreen Document)와 지각 해시 변화 감지가
제대로 도는지 확인할 **비식별 프레임 몇 장**과 그 메타데이터를 넣습니다.
프레임은 변화가 감지된 장면만, WebP 한 장씩입니다.

## 절대 넣지 않는 것

- **화면 전체 영상.** 불변 원칙 §4 입니다. 연속 프레임 묶음도 영상과 같습니다.
- **얼굴이 보이는 프레임.** 참가자 타일이 잡힌 장면은 넣지 않습니다.
- **실명.** 참가자 이름표·채팅 목록·발표자 이름이 찍힌 프레임은 넣지 않습니다.
- **회의 링크·회의 코드.** 주소창이 함께 찍힌 스크린샷도 안 됩니다.
- **개인 화면.** 알림 배너, 열려 있는 메신저, 파일 경로에 사용자 이름이 보이는 장면.

## 넣는 절차

1. 코드가 보이는 **공유 화면 영역만** 잘라 냅니다. 창 테두리·탭·주소창은 잘라 버립니다.
2. 남은 개인 정보를 지웁니다. 지울 수 없으면 그 프레임은 버리고 다시 찍습니다.
3. WebP 로 변환합니다. 원본 PNG 는 저장소에 두지 않습니다.
4. `packages/contracts` 의 `ScreenFrame` 규격에 맞춰 메타데이터를 적습니다.
   `path` 는 이 폴더 기준 상대 경로, `source` 는 `"meet-tab"`,
   `width`·`height` 는 실제 파일 크기와 같아야 합니다.
5. 비식별 처리 전 원본은 `fixtures/meet/private/` 에만 둡니다.
   이 경로는 루트 `.gitignore` 의 `fixtures/**/private/` 로 제외돼 커밋되지 않습니다.
6. 커밋 전에 프레임을 한 장씩 열어 눈으로 확인합니다.
